# Manual de usuario: Panel SIFU Girona

## Para qué sirve
Muestra en una sola pantalla el estado operativo de Girona: servicios, personal, fichajes, pedidos y vacaciones. Se alimenta del **Excel maestro**.

## Accesos directos del escritorio
| Acceso | Qué hace |
|---|---|
| **SIFU GIRONA - Abrir Aplicacion** | Abre el panel en el navegador |
| **MASTER GENERAL GIRONA OKK** | Abre el Excel para editar datos |
| **SIFU GIRONA - Sincronizador Automatico** | Mantiene el panel actualizado con el Excel |

## Uso diario (3 pasos)
1. **Abre el Sincronizador** y déjalo en segundo plano. No lo cierres durante la jornada.
2. **Abre el panel** con el acceso directo.
3. **Edita el Excel cuando haga falta.** Al guardar con `Ctrl+S`, el panel se actualiza solo.

## Secciones principales
- **Panel general:** resumen de los servicios del día.
- **Fichajes:** quién ha fichado, quién no, y contraste con lo planificado.
- **Supervisor virtual:** revisa incidencias y las registra.
- **Pedidos:** seguimiento de pedidos de clientes.
- **Vacaciones y bajas:** calendario de ausencias.
- **Sustituciones:** apoyo para cubrir servicios descubiertos.
- **Calidad y contratos:** cumplimiento y vencimientos.
- **Informes:** análisis, tendencias y exportación.
- **Avisos y chat interno.**

## Buenas prácticas
- Guarda el Excel (`Ctrl+S`) para que los cambios aparezcan en el panel.
- No cambies los nombres de las columnas del Excel maestro. El panel las usa para leer los datos.
- Si el panel no se actualiza, comprueba que el Sincronizador sigue abierto.

## Problemas frecuentes
| Problema | Solución |
|---|---|
| El panel no muestra los cambios | Comprueba que el Sincronizador está abierto y guarda el Excel de nuevo |
| El Excel no se puede guardar | Cierra copias duplicadas del archivo y vuelve a intentarlo |
| La pantalla se ve rara | Recarga con `Ctrl + F5` |
| Falta algún dato | Revisa que esté en el Excel maestro |
